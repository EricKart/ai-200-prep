# 4-week study plan

> For people who are newer to Azure development. About 1.5–2 hours on weekdays and 3 hours on one weekend day.
> Track progress automatically at [aryantripathi.dev/ai-200](https://aryantripathi.dev/ai-200).

## How each study session works

1. **Learn** the module's [lesson](../content/lessons/) (20–30 min). Open the Microsoft Learn link for any section that's new to you.
2. **Practise** that module's questions. Answer first, use the **hint** if you're stuck, then read the reason for every option, not just the right one.
3. **Note** every question you got wrong, with one line on *why*. Redo those three days later.
4. At the end of each week, run that week's **hands-on lab** and re-read the learning path's **cheat sheet**.
