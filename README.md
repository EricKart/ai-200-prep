# AI-200 Prep: free, open, end-to-end

**Pass the Microsoft AI-200 exam (Azure AI Cloud Developer Associate) with one free course.**
Learn every module, practise with hints, run real labs on Azure, then sit three full mock exams.

**▶ Study online:** [aryantripathi.dev/ai-200](https://aryantripathi.dev/ai-200). No sign-up. It saves your progress in your browser.

| | What you get |
|---|---|
| 📖 **Learn** | 28 short lessons, one per module of the official AI-200T00 course, in plain words with diagrams and exam traps |
| ✍️ **Practise** | Questions for every module. Each one has a hint, a reason for every option, and a link to the Microsoft Learn page it comes from |
| 🧪 **Labs** | Hands-on Azure labs for all 9 learning paths, in Bash and PowerShell, each with a cost note and a clean-up step |
| ⏱️ **Mock exams** | 3 full mocks: 60 questions, 120 minutes, weighted like the real exam, no repeats between them |
| 📄 **Cheat sheets** | One page per learning path, plus "Which service?", limits and defaults, CLI commands, and KQL |
| 🎯 **Readiness** | A score for each skill area and a "study this next" list (on the site) |

## Start here (5 minutes)

1. Take the **diagnostic** on [the site](https://aryantripathi.dev/ai-200) to see where you stand.
2. Choose a plan: [2 weeks](guides/study-plan-2-weeks.md) if you already build on Azure, or [4 weeks](guides/study-plan-4-weeks.md) if you're newer.
3. For each module, do **Learn → Practise → Lab**. Use the hint before you look at the answer.
4. When every skill area shows ≥ 80%, take the [mock exams](mocks/). Aim for 750+ before you book.
5. Read the [exam-day guide](guides/exam-day.md) the day before.
